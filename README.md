# Just the Right Spell

Export of the Just the Right Spell site (theperfectspell.com) — single self-contained HTML file.

- `index.html` — the entire site (shop, tarot, blog, grimoire). Open it in a browser as-is, or host it free with GitHub Pages.
- Shop checkouts are real Stripe payment links and work.
- Account sign-up and the $9.99/mo Premium tier are demo-only previews in this build (the page has no backend, so nothing is saved). Persistent accounts need a real backend added on top of this file.
